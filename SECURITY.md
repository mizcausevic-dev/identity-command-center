# Security Policy

## Reporting a Vulnerability

If you discover a security issue in this repository, please do not open a public issue with exploit details.

- Contact: [Mirza Causevic on LinkedIn](https://www.linkedin.com/in/mirzacausevic)
- Include: affected area, reproduction details, impact, and any recommended remediation

## Scope

This repository is a portfolio project demonstrating security-governance UI patterns, identity exception workflows, and operator-facing control-plane design. It is not intended for production deployment without authentication, authorization, audit logging, and deeper policy controls.
